# === Google ad / measurement ===
# Note: googleadservices.com is intentionally NOT blocked at the apex.
# It is the redirector that Chrome opens when a user clicks on a
# "Sponsorizzato" SERP result (URL shape: www.googleadservices.com/
# pagead/aclk?...&adurl=https://destination.com). Blocking the apex
# returns NXDOMAIN to Chrome and the user sees "Sito non raggiungibile"
# even when the destination is legitimate. The actual ad-delivery
# subdomains (partner.googleadservices.com) stay blocked below; the
# apex is also defensively pinned in BlocklistRepository.defaultWhitelist
# as a second layer.
doubleclick.net
googlesyndication.com
googletagmanager.com
googletagservices.com
google-analytics.com
adservice.google.com
pagead2.googlesyndication.com
partner.googleadservices.com
afs.googlesyndication.com
www.googletagservices.com
ad.doubleclick.net
stats.g.doubleclick.net

# === Facebook / Meta tracking ===
# Note: graph.facebook.com is intentionally NOT blocked. It is the
# official Facebook Graph API used by thousands of apps for Facebook
# Login and basic SDK operations. Blocking it breaks legitimate
# functionality. It is also defensively kept in defaultWhitelist in
# BlocklistRepository.kt as a second layer.
# connect.facebook.net is also intentionally NOT blocked: it serves the
# Facebook JavaScript SDK (sdk.js) that powers "Login with Facebook" and
# social widgets on websites; blocking it breaks web Facebook login. It is
# pinned in defaultWhitelist as a second layer. The tracking subdomains
# below stay blocked.
pixel.facebook.com
an.facebook.com
